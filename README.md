# Tech Spec Hub

Tech Spec Hub is a modern, high-performance, and responsive web-based computer hardware catalog application. It is designed to allow authenticated users to browse, search, and inspect detailed architectural specifications and overviews for a curated collection of laptops, high-end workstations, and gaming desktops.

## 🚀 Key Features

* **Secure Authentication**: Built with Laravel Breeze, featuring restricted dashboard and catalog access for authenticated users.
* **Curated System Catalog**: Browse 17+ industry-standard computer systems spanning gaming laptops, ultrabooks, professional workstations, and custom desktop rigs.
* **Interactive Inspection Modals**: Click "View Details" on any system card to trigger a responsive modal showcasing real-world hardware metrics, pricing categories, and system overview summaries.
* **Modern Dark-Themed UI**: Designed with Tailwind CSS, featuring a sleek slate/indigo gradient backdrop, glassmorphism card styling, and smooth transitions.
* **Responsive Grid Layout**: Fully optimized for mobile, tablet, and desktop screens.

---

## 🛠️ Technology Stack

* **Backend**: Laravel (PHP framework handling routing, authentication, and middleware)
* **Frontend**: React.js with Inertia.js (SPA experience without complex API routing)
* **Styling**: Tailwind CSS (Utility-first CSS framework for modern styling)
* **Database**: MySQL (Managed via local server environments like WampServer or XAMPP)
